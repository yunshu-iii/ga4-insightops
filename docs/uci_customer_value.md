# UCI 客户价值 Mart：RFM 与历史价值代理

## 口径与边界

- 来源：`uci_order_fact` 的 `uci_order_v1` 有效订单；只纳入 `is_customer_identified = 1`。
- 快照日：当前批次最后订单日期 2011-12-09 的下一日，即 2011-12-10。
- Recency：快照日与最后订单日的天数；越小越好。
- Frequency：观察期的有效订单数。
- Monetary / `historical_value_gbp`：观察期内的累计有效订单 GMV（GBP）。它是**历史价值代理**，不预测客户未来收入，不是统计或机器学习 LTV 模型。
- RFM：用 `CUME_DIST` 的五分位分数处理并列值，避免将相同订单频率或金额任意拆入不同分位。
