# InsightOps 3–5 分钟演示脚本

本脚本用于录制本地 MVP 演示。所有话术必须说明数据为公开匿名化/合成样例，不能描述为真实生产业务结果。

## 录制前检查

1. 运行 `make test` 与 `make regression-full`，确认通过。
2. 打开 `artifacts/reports/full_ga4_92d/report.html`，或启动本机预览服务后访问报告。
3. 如演示审阅台，按 `docs/streamlit_review_console.md` 启动本地 Streamlit；不得输入密码、展示 `.env` 或原始事件行。

## 展示禁区

- 不展示 `.env`、数据库密码、原始事件级身份字段或本地绝对路径中的个人信息。
- 不把 24 条人工复核候选称为已证实的业务异常，不把贡献切片称为因果归因。
- 不把本机 `make test` 说成 GitHub Actions 已经运行；云端 CI 仍待用户授权。
